# AGAPE — 무조건적인 사랑

〈When Love Responds〉의 AGAPE 파트. 관람객이 실제로 숨을 불어 비눗방울을 만들고, 터진 자리에서 유리꽃이 피어나 자신만의 빛의 정원이 됩니다.

- Vite + Three.js r170
- `public/glb/`와 `src/glass_materials.js`는 AGAPE_LightGarden 패키지 원본 그대로입니다.
- 마이크 소리는 브라우저 안에서 수치로만 계산하며 저장하거나 전송하지 않습니다.

## 주소 옵션

- `?tier=0|1|2` 그래픽 품질 고정 (0 낮음, 2 높음). 없으면 자동 조절
- `?debug` 테스트 도구 활성화

## 마이크 조정

막대를 든 뒤 오른쪽 아래 마이크 버튼에서 감도를 바꿉니다. 막대는 현재 입력, 흰 선은 숨으로 인식하는 기준입니다. 값은 그 기기에 저장됩니다.

## 테스트

`npm run build` 후 `tests/e2e.cjs`를 Playwright로 실행합니다. 시험용 소리는 합성 신호이며 실제 숨소리가 아닙니다.
